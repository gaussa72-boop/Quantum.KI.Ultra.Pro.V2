# AUREALIS INFINITY – Render Web Portal

Static command-center preview for the AUREALIS INFINITY project.

## Current scope
- Responsive dashboard for architecture, agent inventory, DGX cluster enrollment, memory isolation, audit events and staged roadmap.
- All operational values are explicitly labelled as pending/not connected.
- No credentials, user data, API keys or production controls are exposed.
- No backend or live service integrations are included in this preview.

## Render
The repository Blueprint is at the repository root in `aurealis-infinity/render.yaml`. Create a Render Blueprint using that path and the `aurealis-infinity/web-portal` branch. The static publish path is `aurealis-infinity/public`.

## Verification
This UI was authored as static HTML/CSS/JS. It must be previewed and smoke-tested on the deployed Render URL before it is described as live or complete.
